# WebDev-labs

Лабораторні роботи з веброзробки: система обліку відвідуваності студентів (серверна й клієнтська частини).

| Лабораторна | Опис |
|-------------|------|
| [lab-01](lab-01/README.md) | Backend API: Node.js, Express, PostgreSQL, Prisma, валідація Zod |
| [lab-02](lab-02/README.md) | Аутентифікація (JWT), ролі, файли, журнал дій, автотести |
| [lab-03](lab-03/README.md) | WebSocket, Redis, оптимізація БД, розгортання |
| [lab-04](lab-04/README.md) | Клієнт на React: каркас, компоненти, маршрутизація, Axios, темна тема |
| [lab-05](lab-05/README.md) | Клієнт на React: аутентифікація, CRUD, валідація форм, TanStack Query |

Кожна лабораторна запускається окремо, інструкції в її README.
